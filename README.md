# 🧠 Jogo da Memória

Um jogo da memória simples, feito em HTML, CSS e JavaScript puro (sem dependências).

## Como jogar

Abra o arquivo [`index.html`](index.html) em qualquer navegador. Clique nas cartas para virá-las e encontre os pares de emojis iguais no menor tempo e no menor número de jogadas possível.

## Funcionalidades

- Três níveis de dificuldade: Fácil (4x4), Médio (4x6) e Difícil (6x6)
- Contador de jogadas e cronômetro
- Contador de pares encontrados
- Tela de vitória com o resumo da partida
- Botão para reiniciar a qualquer momento

## Estrutura do projeto

| Arquivo       | Descrição                                  |
| ------------- | ------------------------------------------- |
| `index.html`  | Estrutura da página e elementos do jogo      |
| `style.css`   | Estilos visuais e animações das cartas       |
| `script.js`   | Lógica do jogo (embaralhar, comparar, etc.)  |

## Rodando localmente

Não é necessário nenhuma instalação. Basta abrir o `index.html` diretamente no navegador, ou servir a pasta com um servidor estático simples, por exemplo:

```bash
npx serve .
```
